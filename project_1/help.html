Хромоматематическое моделирование

Вариант 3 — Справка по программе

Программа предназначена для визуального исследования математических последовательностей и функций с использованием моделей НММ (Нейронно-Математическое Моделирование) — специальных цветовых схем для отображения числовых данных.

Основные возможности:

  • Работа с базами данных SQLite (.db файлы)
  • Создание и открытие пользовательских баз данных
  • Четыре типа визуализации для каждой формы
  • Интерактивное управление параметрами
  • Поддержка сетки и отображения значений

Форма 1D: Числа Фибоначчи по модулю

Описание

Исследует последовательность чисел Фибоначчи, взятых по модулю. Каждая ячейка окрашивается по модели НММ.

Параметры

  • Модель НММ: НММ_N, НММ_N2, НММ_Rainbow
  • Модуль: число для взятия остатка (1-999)
  • Количество элементов: длина последовательности
  • Grid: отображение сетки

Визуализации

  • Линейная: горизонтальная лента ячеек
  • Столбчатая: гистограмма по значениям
  • Спираль: радиальная раскладка точек
  • Мозаика: табличное представление

Форма 2D: Ker(|X² - Y²|)

Описание

Исследует функцию Ker(n) — количество делителей числа n, где n = |X² - Y²|. Создает цветную матрицу.

Параметры

  • Модель НММ: выбор цветовой схемы
  • Aspect: соотношение сторон ячеек (0.1-5.0)
  • Диапазоны X/Y: область вычислений (1-200)
  • Value: показ числовых значений в ячейках
  • Grid: отображение сетки

Визуализации

  • Цветная матрица: |X²-Y²| с цветами НММ
  • По Ker: исходная функция Ker(X²-Y²)
  • Спираль 2D: спиральная раскладка Ker
  • Градиентная: тестовая градиентная сетка
