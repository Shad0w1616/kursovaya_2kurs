Горячие клавиши

Быстрый доступ ко всем функциям программы:

Функция Клавиша Описание
Создать новую БД Ctrl+N Создает копию шаблонной БД
Открыть БД Ctrl+O Загружает существующую БД
1D — Фибоначчи Ctrl+1 Открывает форму чисел Фибоначчи
2D — Ker(разность квадратов) Ctrl+2 Открывает форму Ker матрицы
Справка F1 Открывает основную справку
О программе Ctrl+A Информация об авторе
Выход Ctrl+Q Закрывает программу
